# Этап 2: Аутентификация

## Выполнено

✅ **Страница регистрации** (`register.html`)
- Форма регистрации с полями: email, nickName, password, confirmPassword
- Валидация на клиенте
- Интеграция с API `/api/Auth/register`

✅ **Страница входа** (`login.html`)
- Форма входа с полями: email, password
- Валидация на клиенте
- Интеграция с API `/api/Auth/login`

✅ **Модуль аутентификации** (`js/auth.js`)
- `register()` - регистрация
- `login()` - вход
- `logout()` - выход
- `getCurrentUser()` - получение информации о пользователе
- `isAuthenticated()` - проверка авторизации
- `refreshToken()` - обновление токена

✅ **Обновлена главная страница**
- Отображение информации о пользователе
- Кнопка выхода
- Проверка авторизации

## Особенности

- JWT токены хранятся в httpOnly cookies (устанавливаются сервером)
- Автоматическое перенаправление на главную после успешного входа/регистрации
- Обработка ошибок с отображением сообщений
- Валидация форм на клиенте
