# Этап 4: Чат и Аудио

## Выполнено

✅ **Модуль чата** (`js/chat.js`)
- `init()` - инициализация SignalR подключения
- `sendMessage()` - отправка сообщений
- `getMessages()` - получение истории сообщений
- `leaveGroup()` - отключение от группы
- Интеграция с SignalR Hub

✅ **Модуль аудио** (`js/audio.js`)
- `init()` - инициализация Janus Gateway
- `attachAudioBridge()` - подключение к AudioBridge плагину
- `joinRoom()` - присоединение к аудио комнате
- `toggleMute()` - переключение микрофона
- `disconnect()` - отключение
- Интеграция с WebRTC/Janus

✅ **Страница группы** (`group.html`)
- Отображение информации о группе
- Список участников
- Чат в реальном времени (SignalR)
- История сообщений
- Аудио каналы
- Подключение к аудио каналу через Janus
- Создание аудио канала
- Присоединение к группе (если не участник)

## Особенности

- SignalR для чата в реальном времени
- Janus Gateway для аудио через WebRTC
- Автоматическое подключение при загрузке страницы
- Очистка подключений при закрытии страницы
