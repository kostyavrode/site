# Этап 1: Базовая структура

## Цель
Создать базовую структуру проекта с минималистичным дизайном в стиле IDE.

## Задачи

### 1.1. Базовый CSS (темная тема, минимализм)
- Цветовая схема (темный фон, светлый текст)
- Типографика (моноширинный шрифт)
- Базовые компоненты (кнопки, инпуты, карточки)

### 1.2. Базовый HTML структура
- Главная страница (index.html)
- Базовая навигация
- Layout компоненты

### 1.3. API клиент (js/api.js)
- Базовые функции для HTTP запросов
- Обработка ошибок
- Управление токенами

### 1.4. Утилиты (js/utils.js)
- Вспомогательные функции
- Обработка дат, строк и т.д.

## Цветовая схема

```css
/* Основные цвета */
--bg-primary: #1e1e1e;        /* Темный фон (как VS Code) */
--bg-secondary: #252526;      /* Вторичный фон */
--bg-tertiary: #2d2d30;       /* Третичный фон */
--text-primary: #cccccc;      /* Основной текст */
--text-secondary: #858585;    /* Вторичный текст */
--accent-green: #4ec9b0;      /* Зеленый акцент (как в терминале) */
--accent-blue: #569cd6;       /* Синий акцент */
--accent-yellow: #dcdcaa;     /* Желтый акцент */
--border-color: #3e3e42;      /* Цвет границ */
--hover-bg: #2a2d2e;          /* Фон при наведении */
--error: #f48771;             /* Ошибка */
--success: #4ec9b0;           /* Успех */
```

## Шрифты

```css
font-family: 'Consolas', 'Monaco', 'Courier New', monospace;
```

- Минималистичный стиль

### Инпут
- Темный фон
- Граница

### Карточка
- Темный фон
- Граница

Базовая структура с темным минималистичным дизайном готова.
