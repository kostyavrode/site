# Этап 3: Управление группами

## Выполнено

✅ **Модуль групп** (`js/groups.js`)
- `createGroup()` - создание группы
- `getGroupById()` - получение группы по ID
- `getUserGroups()` - получение групп пользователя
- `searchGroups()` - поиск групп
- `joinGroup()` - присоединение к группе
- `leaveGroup()` - выход из группы
- `getGroupMembers()` - получение участников
- `updateGroup()` - обновление группы
- `deleteGroup()` - удаление группы

✅ **Страница групп** (`groups.html`)
- Создание группы (модальное окно)
- Поиск групп
- Отображение своих групп
- Отображение результатов поиска
- Переход к странице группы
