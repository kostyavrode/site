# План разработки веб-сайта

## 🎨 Дизайн концепция

- **Стиль:** Минималистичный, напоминающий старый интернет
- **Цветовая схема:** Темные тона (темно-серый, черный фон, зеленый/синий текст как в терминале/IDE)
- **Вдохновение:** IDE для разработки (VS Code, Terminal, старые текстовые редакторы)
- **Принципы:** Легкий, быстрый, функциональный

## 📋 Функционал

### Auth Service
- Регистрация пользователя
- Вход в систему
- Выход
- Обновление токена (refresh token)
- Профиль пользователя

### Groups Service
- Создание группы
- Поиск групп
- Присоединение к группе (с паролем/без)
- Просмотр своих групп
- Выход из группы
- Просмотр информации о группе

### Chat Service
- Подключение к чату через SignalR
- Отправка сообщений
- Просмотр истории сообщений
- Обновление в реальном времени

### Audio Service
- Создание аудио канала
- Подключение к аудио каналу через WebRTC/Janus
- Управление микрофоном (вкл/выкл)
- Просмотр участников аудио канала

## 🏗️ Этапы разработки

### Этап 1: Базовая структура
- Создать структуру проекта (HTML, CSS, JS)
- Настроить базовый стиль (темная тема, минимализм)
- Создать навигацию
- Настроить API клиент

### Этап 2: Аутентификация
- Страница регистрации
- Страница входа
- Обработка JWT токенов (сохранение в cookies/httpOnly)
- Обновление токенов
- Защита маршрутов

### Этап 3: Группы
- Создание группы
- Поиск групп
- Присоединение к группе
- Просмотр своих групп
- Просмотр информации о группе

### Этап 4: Чат
- Подключение к SignalR
- Интерфейс чата
- Отправка сообщений
- История сообщений
- Обновление в реальном времени

### Этап 5: Аудио каналы
- Создание аудио канала
- Подключение к Janus Gateway через WebRTC
- Управление микрофоном
- Просмотр участников

### Этап 6: Главная страница
- Дашборд с группами
- Навигация
- Интеграция всех компонентов

### Этап 7: Оптимизация
- Минификация CSS/JS
- Оптимизация загрузки
- Полировка UI/UX
- Тестирование

## 📁 Структура проекта

```
site/
├── index.html              # Главная страница
├── login.html              # Страница входа
├── register.html           # Страница регистрации
├── groups.html             # Управление группами
├── group.html              # Страница группы (чат + аудио)
├── css/
│   ├── main.css            # Основные стили
│   └── components.css      # Стили компонентов
├── js/
│   ├── api.js              # API клиент
│   ├── auth.js             # Аутентификация
│   ├── groups.js           # Управление группами
│   ├── chat.js             # Чат (SignalR)
│   ├── audio.js            # Аудио (WebRTC/Janus)
│   └── utils.js            # Утилиты
├── lib/
│   ├── signalr.js          # SignalR клиент
│   └── janus.js            # Janus Gateway клиент (если нужен)
└── DEVELOPMENT_PLAN.md     # Этот файл
```

## 🛠️ Технологии

- **HTML5** - структура
- **CSS3** - стили (минималистичные, темные)
- **Vanilla JavaScript** - логика (без фреймворков для легкости)
- **SignalR** - для чата
- **WebRTC** - для аудио
- **Fetch API** - для HTTP запросов

## 🎯 Принципы

1. **Легкость** - минимальные зависимости, vanilla JS
2. **Скорость** - быстрая загрузка, оптимизация
3. **Функциональность** - весь функционал сервисов
4. **Минимализм** - чистый интерфейс без излишеств
5. **Темная тема** - IDE-подобный дизайн
