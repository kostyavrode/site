# Audio Chat - Веб-интерфейс

Минималистичный веб-интерфейс для аудио чата в стиле IDE.

## 🎨 Дизайн

- **Стиль:** Минималистичный, темная тема
- **Вдохновение:** IDE (VS Code), терминал, старые текстовые редакторы
- **Цвета:** Темный фон, зеленый/синий акценты

## 📁 Структура

```
site/
├── index.html          # Главная страница
├── login.html          # Вход
├── register.html       # Регистрация
├── groups.html         # Управление группами
├── group.html          # Страница группы (чат + аудио)
├── css/
│   └── main.css        # Основные стили
├── js/
│   ├── api.js          # API клиент
│   ├── auth.js         # Аутентификация
│   ├── groups.js       # Группы
│   ├── chat.js         # Чат (SignalR)
│   ├── audio.js        # Аудио (Janus/WebRTC)
│   └── utils.js        # Утилиты
└── README.md           # Этот файл
```

## 🚀 Запуск

### Вариант 1: Простой HTTP сервер (Python)

```powershell
cd site
python -m http.server 8000
```

Откройте в браузере: http://localhost:8000

### Вариант 2: VS Code Live Server

1. Откройте папку `site` в VS Code
2. Установите расширение "Live Server"
3. Нажмите правой кнопкой на `index.html`
4. Выберите "Open with Live Server"

### Вариант 3: Node.js (http-server)

```powershell
npx http-server site -p 8000
```

## 📋 Функционал

### ✅ Аутентификация
- Регистрация
- Вход/выход
- Управление токенами (httpOnly cookies)

### ✅ Группы
- Создание группы
- Поиск групп
- Присоединение к группе (с паролем/без)
- Просмотр своих групп

### ✅ Чат
- Подключение через SignalR
- Отправка сообщений
- История сообщений
- Обновление в реальном времени

### ✅ Аудио
- Создание аудио канала
- Подключение через Janus Gateway (WebRTC)
- Управление микрофоном
- Просмотр участников

## ⚙️ Настройка

### URL сервисов

Измените URL сервисов в `js/api.js`:

```javascript
baseUrls: {
    auth: 'http://localhost:5001',
    groups: 'http://localhost:5002',
    chat: 'http://localhost:5003',
    audio: 'http://localhost:5004'
}
```

### Janus Gateway

URL Janus Gateway настраивается в `js/audio.js`:

```javascript
const janusUrl = 'http://localhost:8088/janus';
```

## 📚 Зависимости

### Внешние библиотеки (загружаются из CDN)

- **SignalR:** `@microsoft/signalr@7.0.0` - для чата
- **WebRTC Adapter:** `adapter-webrtc@7.7.0` - для WebRTC
- **Janus Gateway JS:** `janus.js` - для аудио

### Встроенные

- Vanilla JavaScript (ES6+)
- CSS3
- HTML5

## 🔧 Разработка

### Добавление новой страницы

1. Создайте HTML файл
2. Подключите `css/main.css`
3. Подключите необходимые JS модули
4. Используйте компоненты из `main.css`

### Добавление нового модуля

1. Создайте файл в `js/`
2. Экспортируйте объект с методами
3. Подключите в нужных страницах

## 📝 Примечания

- Токены хранятся в httpOnly cookies (устанавливаются сервером)
- SignalR использует WebSocket для реального времени
- Janus Gateway требуется для работы аудио
- Все запросы к API требуют авторизации (кроме регистрации/входа)

## 🐛 Известные проблемы

- При первом подключении к Janus может потребоваться разрешение на микрофон
- SignalR может не работать через некоторые прокси (используйте прямой доступ)
